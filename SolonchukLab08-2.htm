Використання глобальних стилів

HTML

HTML використовується для створення структури Web-сторінок. За допомогою HTML можна додавати текст, таблиці, зображення, посилання та інші елементи.

HTML є основою більшості сучасних Web-сайтів. Він визначає структуру документа та його основні елементи.

CSS

CSS використовується для оформлення Web-сторінок. За допомогою стилів можна змінювати колір, розмір, шрифт та розташування елементів.

Глобальні стилі дозволяють задавати однакове оформлення для багатьох елементів документа одночасно.
