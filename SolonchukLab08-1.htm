Використання стилів у HTML

Сучасні Web-технології дозволяють створювати зручні та красиві сторінки. За допомогою CSS можна змінювати зовнішній вигляд тексту, його колір, розмір та розташування.

CSS використовується для оформлення HTML-документів. Стилі дозволяють зробити сторінку більш привабливою.

Стиль можна задавати окремо для кожного елемента сторінки.

Використання стильових призначень дозволяє змінювати не тільки текст, але й фон, рамки, відступи та багато інших властивостей елементів Web-сторінки.
